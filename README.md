# Queensland Geoscience Data (geoscience-data-qld-gov-au)

Queensland Geoscience Data is a state government open-data portal for Australia running **CKAN**, exposing a standardized catalog API over ~190,463 datasets.

**URL:** [Visit APIs.json URL](https://raw.githubusercontent.com/api-evangelist/geoscience-data-qld-gov-au/refs/heads/main/apis.yml)

**Run:** [Capabilities Using Naftiko](https://github.com/naftiko/fleet?utm_source=api-evangelist&utm_medium=readme&utm_campaign=geoscience-data-qld-gov-au-api-evangelist&utm_content=repo)
